1. System Overview

The Digital School Report System is a web-based management platform designed to automate the academic reporting process for multi-branch primary schools. The system features Role-Based Access Control (RBAC), offline capabilities via PWA integration, and comprehensive student lifecycle management from registration to report card generation.

Key Technology Stack:
  • Backend: PHP 8.x with PDO
  • Database: MySQL / MariaDB
  • Frontend: HTML5, CSS3, JavaScript
  • Offline: Service Workers & Manifest (PWA)

4. Detailed Registration Process

The registration module is dynamically built to capture comprehensive student data. When a user selects the Student role, the system activates conditional logic to collect:

  • Student Identity: Full Name, DOB, Age, Nationality, and LIN Number.
  • Academic Context: School Branch selection and Current Class assignment.
  • Guardian Context: Name, Phone, Profession, and Place of Work.
  • Health/Social Status: Optional tracking for chronic conditions or orphan status.

5. PWA & Offline Functionality

To ensure reliability in areas with intermittent connectivity, the system implements Progressive Web App standards:

  • Service Worker: Caches core CSS, JS, and UI assets for instant loading.
  • Manifest: Allows the system to be installed on Windows/macOS desktops as a standalone app.
  • Data Persistence: Cached report cards remain viewable even when the server is unreachable.
